# Giacomo Ricci – UX/UI Portfolio

Sito statico (HTML, CSS, JavaScript puro). Nessun build, nessuna dipendenza.
Online su https://giacomoricciuxui.com

## Struttura
```
index.html            pagina unica
404.html              pagina di errore
assets/css/style.css  stili
assets/js/main.js     progetti, chat, QR code
assets/images/        copertine dei progetti
assets/og-image.jpg   anteprima per LinkedIn (1200x630)
assets/Giacomo_Ricci_CV_2026.pdf
favicon.svg / favicon.ico / apple-touch-icon.png
robots.txt / sitemap.xml / vercel.json
```

## Come aggiornare il sito
Modifica i file, fai commit e push su GitHub: Vercel ripubblica in automatico.
Vercel: Framework Preset "Other", nessun Build Command, nessun Output Directory.

## Provarlo in locale
Apri `index.html` nel browser.
